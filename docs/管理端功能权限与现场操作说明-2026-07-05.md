# 管理端功能权限与现场操作说明

时间：2026-07-05
入口：`admin.html`
核心脚本：`src/admin.js`
核心后端：`server/index.js`

## 1. 这份文档解决什么问题

管理端不是一个普通展示页面，而是赛事现场的“控制台”。它负责四件事：

1. 控流程：当前阶段、倒计时、大屏显示。
2. 控内容：星锐资料、赛道信息、队伍成员、作品审核。
3. 控权限：用户角色、管理员、评委、选手、观众。
4. 控结果：投票窗口、评委锁分、最终排行榜快照。

如果现场只有一个判断原则，就是：前端按钮只是操作入口，最终权限和业务规则必须以后端 API 为准。

## 2. 关键术语

- 管理端：后台页面，文件是 `admin.html`，脚本是 `src/admin.js`。
- API：Application Programming Interface，应用程序接口。这里指浏览器调用后端的 HTTP 地址，例如 `/api/admin/results/publish`。
- Repository：数据仓库层，负责读写 JSON 文件或 MySQL 表。例如投票使用 `voteResultsRepository`。
- strict 鉴权：后端必须检查登录 session 和角色权限。生产环境必须开启 `AUTH_ENFORCEMENT=strict`。
- 锁定评分：管理员确认所有评委都提交后，将评分状态改成 locked，后续不能再改。
- 快照：最终结果发布时生成的一份固定结果。排行榜和大屏结果页读取快照，不再随实时投票变化。

## 3. 角色与权限归属

| 角色 | 主要入口 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 管理员 admin | `admin.html` | 管流程、管用户、审核作品、开关投票、锁分、发布结果 | 不作为普通观众重复投票，不代替评委打分 |
| 选手 player | `site.html#team`、队伍工作台 | 加入队伍、队长提交作品 | 非队长不能提交、撤回、上传作品截图 |
| 评委 judge | `site.html#judge` | 对已发布作品评分、暂存、正式提交 | 不能评分未发布作品，正式提交/锁分后不能修改 |
| 观众 public | `site.html#gallery` | 浏览已发布作品、投一票 | 不能投未发布作品，投票关闭后不能投票或取消 |

角色权限基础定义在 `src/logic.js` 的 `getRolePermissions()`。后端接口再用 `server/index.js` 的 `enforcePermission()` 做最终校验。

## 4. 管理端模块地图

### 4.1 控制台

用途：看当前系统概览、API 状态、流程状态和关键数据。

代码位置：

- 页面结构：`admin.html`
- 渲染逻辑：`src/admin.js`
- 后端健康检查：`GET /api/health`

现场用法：开场前先看这里，确认 API 连接正常、后台数据同步正常。

### 4.2 流程控制台

用途：切换赛事阶段、控制主倒计时和路演计时。

常用操作：

- 设置当前阶段。
- 保存主倒计时时长。
- 启动/暂停倒计时。
- 配置路演队伍和 15 分钟路演计时。

核心 API：

- `PATCH /api/admin/stage`
- `POST /api/countdown/start`
- `POST /api/roadshow/start`

注意：倒计时显示在前台和大屏上，管理员改完后要刷新或等待轮询同步。

### 4.3 大屏控制

用途：控制主会场大屏显示哪个阶段页面。

核心概念：

- 跟随流程：大屏跟着当前赛事阶段走。
- 锁定显示：管理员指定大屏固定在某个页面，不跟随当前阶段。

核心 API：

- `PATCH /api/admin/screen-override`

现场建议：主持人串场或临时等待时，用“锁定显示”；正常推进时，恢复“跟随流程”。

### 4.4 内容管理

用途：维护首页、星锐档案、业务赛道、作品相关内容。

常见内容：

- 星锐人员资料。
- 赛道标题、英文名、业务描述、交付物说明。
- 飞书文档链接。

风险点：飞书链接只是 URL，系统不能替你修改飞书文档权限。所有作品文档建议设置为公司内可访问。

### 4.5 数据与投票

用途：管理投票窗口、导出数据、审核作品、查看评委进度。

核心 API：

- `GET /api/vote-results`
- `PATCH /api/admin/vote-window`
- `GET /api/admin/works`
- `PATCH /api/admin/works/:id/status`
- `GET /api/admin/judge/progress`
- `POST /api/admin/judge/lock`

重要规则：

- 观众只能投已发布作品。
- 公开投票接口不会返回 voters 明细，只返回票数和投票人数。
- 作品状态为 `published` 后，才进入作品展厅、投票和评委评分范围。

### 4.6 排行榜

用途：发布最终结果。

发布前置条件：

1. 投票窗口已关闭。
2. 所有已发布作品都存在投票结果行。
3. 所有评委对所有已发布作品完成评分。
4. 管理员已锁定专家评分。

核心 API：

- `POST /api/admin/results/publish`
- `GET /api/results/latest`

重要规则：最终发布生成 snapshot。发布后前台排行榜读取 snapshot，而不是实时重算。

### 4.7 队伍与成员

用途：查看五支队伍成员、角色覆盖、队长和队员情况。

核心 API：

- `GET /api/teams`
- `POST /api/admin/team-members`
- `DELETE /api/admin/team-members`
- `PATCH /api/admin/teams/:id/status`

重要规则：

- 队伍锁定后，选手不能再随意加入、退出或换角色。
- 只有队长能提交、撤回、上传本队作品资产。

### 4.8 用户管理

用途：查看和编辑用户角色。

核心 API：

- `GET /api/admin/users`
- `POST /api/admin/users`
- `PATCH /api/admin/users/:id`

现场前必须确认：

- 8-9 位评委都有 `judge` 角色。
- 管理员都有 `admin` 角色。
- 参赛选手都有 `player` 角色。
- 其他公司员工默认可以作为 `public` 观众。

### 4.9 系统状态

用途：查看系统连接、当前数据源、版本和基础状态。

建议现场开场前检查：

- API 正常。
- 后台数据已同步。
- 当前用户确认为管理员。
- 环境变量 `AUTH_ENFORCEMENT=strict` 已开启。

### 4.10 操作日志

用途：追溯管理员做过什么。

核心 API：

- `GET /api/admin/audit-logs`

典型日志：

- 阶段切换。
- 投票窗口开关。
- 作品审核。
- 评委锁分。
- 结果发布。

## 5. 现场推荐操作顺序

### 活动前 30 分钟

1. 用管理员账号登录管理端。
2. 打开控制台，确认 API 和数据同步正常。
3. 打开用户管理，确认管理员、评委、选手角色。
4. 打开队伍与成员，确认队长和队员。
5. 打开内容管理，确认赛道和飞书链接。

### 组队结束

1. 打开队伍与成员。
2. 确认每队人数和队长。
3. 锁定队伍。

### 作品提交结束

1. 打开数据与投票。
2. 逐个审核作品。
3. 将合格作品发布为 `published`。
4. 从作品展厅打开详情，确认截图、简介、飞书文档链接可见。

### 投票阶段

1. 开启投票窗口。
2. 让观众从作品展厅投票。
3. 关闭投票窗口。
4. 导出或截图保存投票结果。

### 评分阶段

1. 确认评委端能看到所有已发布作品。
2. 等每位评委正式提交。
3. 打开数据与投票，查看评委提交进度。
4. 全部提交后，锁定专家评分。

### 结果发布

1. 确认投票已关闭。
2. 确认评分已锁定。
3. 打开排行榜模块。
4. 勾选确认。
5. 发布排行结果。
6. 打开前台排行榜和大屏结果页核对。

## 6. 常见异常与处理

| 异常 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 管理员进不了后台 | 当前用户没有 admin 角色或 strict 鉴权未配置 | 用户管理补 admin 角色，重新登录 |
| 观众投不了票 | 投票窗口关闭、作品未发布、用户不是 public | 检查作品状态和投票窗口 |
| 评委看不到作品 | 作品未发布 | 管理员先审核发布作品 |
| 评委提交后不能改 | 这是正常规则 | 如确需修改，只能走管理员现场决策，不建议临时改库 |
| 发布排行榜按钮不可用 | 投票未关闭或评分未锁定 | 先关闭投票，再锁定专家评分 |
| 飞书文档打不开 | 文档权限没有开放 | 到飞书里设置公司内可访问 |
| 图片丢失 | 上传目录不持久化 | 检查服务器 `assets/uploads/works/` 是否被部署覆盖 |

- [ ] 管理员账号可进入 `admin.html`。
- [ ] 评委名单和实际评委人数一致。
- [ ] 选手名单和队伍成员一致。
- [ ] 所有作品飞书文档公司内可访问。
- [ ] 上传目录持久化。
- [ ] 投票窗口开关可用。
- [ ] 评委评分提交进度可见。
- [ ] 最终发布流程显示“关闭投票 + 锁定评分 + 发布快照”。
