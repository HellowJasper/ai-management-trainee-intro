# 作品轮播大图查看器设计

## 目标

在作品详情页中，用户点击轮播图片后可以打开全屏大图，并在大图层内前后切换该作品的全部展示截图。

## 交互

- 点击轮播中的真实图片打开全屏灯箱；空状态不可打开。
- 灯箱显示当前图片、序号和图片总数。
- 左右箭头、键盘方向键和移动端水平滑动均可切换图片。
- `Esc`、右上角关闭按钮或点击遮罩层可关闭。
- 仅一张图片时隐藏左右切换按钮。
- 打开灯箱后锁定页面滚动，关闭后恢复。

## 技术边界

- 复用 `src/site.js` 中作品详情已经生成的 `slides` 数组，不新增后端字段。
- 灯箱 DOM 由前端渲染，样式放在 `src/site.css`。
- 不改变作品上传数量、单张 8MB 校验、提交接口及作品数据结构。
- 轮播图与灯箱共享当前图片索引，在灯箱内切换后，底层轮播保持同步。

## 可用性与适配

- 灯箱使用对话框语义，关闭按钮和切换按钮提供中文可访问名称。
- 桌面端优先显示完整图片，不裁切；移动端保留足够的关闭和滑动区域。
- 兼容已上传的本地资源路径和远程 URL。

## 验证

- 自动测试覆盖：大图入口、灯箱结构、左右切换、关闭行为和移动端样式。
- 浏览器验证覆盖：桌面宽屏和移动端视口，确认图片不溢出、按钮不重叠、页面背景不会跟随滚动。
